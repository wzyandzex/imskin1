# IMSkin 领域模型与数据契约

> 版本：v1.0
> 状态：目标契约
> 最后更新：2026-08-15
> 关联：`docs/00-总规划与开发基线.md`、ADR-002、ADR-003、ADR-006

## 1. 目的

本文冻结后续实现必须共享的领域语言、对象边界、状态机和迁移规则。当前代码中的 `DesignBrief`、`VisualSpec`、`SkinManifest`、`ProjectStore` 等继续作为迁移起点，但不透明的 `Version.data: Record<string, unknown>` 和临时 `images[]` 不再是长期契约。

规则：

- 领域对象使用 camelCase；平台格式私有字段留在 adapter 内。
- 跨包 DTO 以后集中到 `@imskin/contracts`。
- 持久化对象必须带 `schemaVersion`。
- 所有 ID 在项目内稳定；导出文件名不是领域 ID。
- 所有版本快照创建后不可变。
- 时间、随机数和外部 provider 版本必须进入 provenance，不能隐式影响可复现性。

## 2. 核心术语

| 术语 | 定义 |
|---|---|
| Project | 一项皮肤创作，拥有版本树和目标出口 |
| DesignSnapshot | 某个 Version 的完整、可恢复、不可变设计文档 |
| DesignBrief | 用户意图与系统推断的结构化合同 |
| VisualSpec | 平台无关的视觉、布局与行为 token |
| AssetBundle | 设计层资产与四个目标变体资产的集合 |
| TargetVariant | 一个确定出口的资源、能力、预览、QA 和产物状态 |
| Outlet | `sogou_pc`、`sogou_android`、`baidu_pc`、`baidu_android` |
| Element | 可被点选、反馈、保护、合并和 QA 定位的稳定语义节点 |
| ChangeInstruction | A5 输出的结构化修改指令 |
| PackageArtifact | 某出口一次构建得到的候选包及其元数据 |
| Evidence | 支撑某项事实或交付等级的可审计记录 |
| Provenance | 输入、依赖、工具、模型、随机种子和输出指纹的溯源 |

## 3. 标识与枚举

### 3.1 Outlet

```ts
export type Outlet =
  | "sogou_pc"
  | "sogou_android"
  | "baidu_pc"
  | "baidu_android";

export type Vendor = "sogou" | "baidu";
export type DeviceClass = "pc" | "android";
```

禁止继续在公共契约中混用：

- `mobile` 与 `android`；
- `sogouPc` 与 `sogou_pc`；
- `platform: sogou` 加另一个自由字符串 device。

边界层可以转换旧值，但领域内部只用 `Outlet`。

### 3.2 ID 规则

建议前缀：

| 对象 | 前缀 | 示例 |
|---|---|---|
| Project | `prj_` | `prj_01...` |
| Version | `ver_` | `ver_01...` |
| Feedback | `fb_` | `fb_01...` |
| Asset | `ast_` | `ast_01...` |
| Artifact | `art_` | `art_01...` |
| Job | `job_` | `job_01...` |
| QA Report | `qa_` | `qa_01...` |
| Evidence | `ev_` | `ev_01...` |

本地开发可保留现有 `p1/v1` 作为旧 schema ID。新 ID 必须不可预测且跨进程不冲突；测试通过注入 ID factory 获得确定性。

## 4. 聚合关系

```text
Project
  ├─ versions: Version[]（树）
  ├─ targetOutlets: Outlet[]
  └─ currentVersionId

Version
  ├─ parentVersionId?
  ├─ lifecycle
  ├─ snapshot: DesignSnapshot
  ├─ feedbackIds[]
  └─ confirmation?

DesignSnapshot
  ├─ brief: DesignBrief
  ├─ visualSpec: VisualSpec
  ├─ elements: ElementCatalog
  ├─ assetBundle: AssetBundle
  ├─ targetVariants: Record<Outlet, TargetVariant>
  ├─ preferences: ProjectPreference[]
  └─ provenance: Provenance

TargetVariant
  ├─ previewProfile
  ├─ capabilities
  ├─ assetSet
  ├─ job?
  ├─ qaReports[]
  ├─ artifact?
  └─ deliveryLevel
```

资产二进制可存对象存储/IndexedDB，Snapshot 保存 content hash 和引用；项目文件的“自包含模式”可把二进制嵌入或随包携带，但语义不变。

## 5. Project 与 Version

```ts
export interface ProjectV1 {
  schemaVersion: 1;
  id: string;
  name: string;
  targetOutlets: Outlet[];
  rootVersionIds: string[];
  currentVersionId?: string;
  createdAt: string;
  updatedAt: string;
}

export type VersionLifecycle =
  | "draft"
  | "brief_pending_confirmation"
  | "generating"
  | "ready"
  | "confirmed"
  | "exporting"
  | "completed"
  | "blocked"
  | "failed";

export interface VersionV1 {
  schemaVersion: 1;
  id: string;
  projectId: string;
  parentVersionId: string | null;
  label?: string;
  lifecycle: VersionLifecycle;
  snapshot: DesignSnapshotV1;
  createdAt: string;
  confirmation?: VersionConfirmation;
  failure?: Diagnostic;
}

export interface VersionConfirmation {
  confirmedAt: string;
  snapshotHash: string;
  confirmedBy: "local_user" | string;
}
```

### 5.1 生命周期不变量

- Brief 未确认不能进入完整生成。
- QA 通过可进入 `ready`，但不能自动进入 `confirmed`。
- `confirmed` 只能由显式用户命令产生，并保存 `snapshotHash`。
- 确认后的任何修改必须 fork 新版本，新版本回到 `draft`。
- `exporting/completed` 是版本工作流状态，不代表任何出口已真机验证。
- `blocked/failed` 必须带结构化 Diagnostic。
- 旧 `exported` 迁移为 `completed`，并附 warning：它不证明 `install_verified`。

## 6. DesignBrief

```ts
export interface DesignBriefV1 {
  schemaVersion: 1;
  styleKeywords: string[];
  palette: {
    primary: string;
    accent?: string;
    background?: string;
  };
  mood: string;
  materialDirection?: string;
  cornerRadius: "small" | "medium" | "large";
  typography?: {
    familyPreference?: string;
    weightPreference?: number;
  };
  motionIntent: MotionIntent[];
  soundIntent?: SoundIntent;
  hapticIntent?: HapticIntent;
  references: ReferenceAsset[];
  targetOutlets: Outlet[];
  inferredFields: string[];
  explicitFields: string[];
}
```

约束：

- 颜色入库前统一为 `#RRGGBB` 或明确支持的 alpha 格式。
- `inferredFields` 和 `explicitFields` 使用 JSON Pointer；同一路径不得同时存在。
- 模型返回必须经过运行时 parse/normalize，不能只用 TypeScript 类型断言。
- 外部素材只存引用、MIME、尺寸、hash、来源和授权声明，不在日志中保存原始内容。
- 视频关键帧和动效意图必须分开，不能把“抽到静态帧”视为已实现动效理解。

## 7. VisualSpec 与 ElementCatalog

```ts
export interface VisualSpecV1 {
  schemaVersion: 1;
  themeStrategy: "light" | "dark" | "paired";
  tokens: DesignTokens;
  layout: LayoutIntent;
  behavior: BehaviorIntent;
}

export interface ElementDescriptor {
  elementId: string;
  role: ElementRole;
  tokenPaths: string[];
  assetRoles: AssetRole[];
  parentElementId?: string;
  supportedOutlets: Outlet[];
}

export interface ElementCatalog {
  schemaVersion: 1;
  elements: Record<string, ElementDescriptor>;
}
```

### 7.1 element_id 命名空间

首版保留以下稳定根节点：

```text
keyboard.background
keyboard.key.normal
keyboard.key.pressed
keyboard.key.special
keyboard.key.text
candidateBar.background
candidateBar.composingText
candidateBar.candidateText
candidateBar.selected.background
candidateBar.selected.text
candidateBar.indexText
statusBar.background
statusBar.icon.language
statusBar.icon.keyboard
mobile.t9.key
mobile.qwerty.key
mobile.panel.symbol
mobile.panel.number
mobile.panel.emoji
mobile.sound.keypress
mobile.motion.keypress
mobile.gesture.swipe
```

规则：

- `element_id` 表达语义，不包含版本号、平台文件路径或数组索引。
- 出口差异用 TargetVariant 表达，不能创建 `baidu_candidate_blue_2` 一类 ID。
- 列表内实例需要稳定 instance key，例如 `keyboard.key.normal/q`，但通用反馈可指向父元素。
- 重命名 element_id 是 schema migration，不能普通重构。

## 8. AssetBundle

```ts
export interface AssetBundleV1 {
  schemaVersion: 1;
  designLayer: AssetSet;
  outletLayers: Record<Outlet, AssetSet>;
}

export interface AssetSet {
  assets: AssetDescriptor[];
  completeness: AssetCompleteness;
}

export interface AssetDescriptor {
  id: string;
  elementId: string;
  role: AssetRole;
  mediaType: string;
  contentHash: string;
  byteLength: number;
  source: AssetSource;
  dimensions?: { width: number; height: number };
  density?: "mdpi" | "hdpi" | "xhdpi" | "xxhdpi" | "xxxhdpi";
  orientation?: "any" | "portrait" | "landscape";
  theme?: "light" | "dark" | "any";
  state?: "normal" | "hover" | "pressed" | "disabled" | "selected";
  nineSlice?: { left: number; top: number; right: number; bottom: number };
  frame?: { index: number; total: number; durationMs: number };
  storage: AssetReference;
  provenance: Provenance;
}

export interface AssetCompleteness {
  required: number;
  present: number;
  missingRoles: AssetRole[];
  closedReferences: boolean;
}
```

不变量：

- `contentHash`、`byteLength` 和 `mediaType` 必填。
- 所有 adapter 引用必须能解析到 AssetDescriptor，闭合率 100%。
- 必需资源由 outlet 的 AssetProfile 定义，不由调用方临时决定。
- 图片生成失败不能生成虚假占位并标记完整；必须列入 missingRoles。
- 同一资产内容可以被多个变体引用，但 target variant 必须拥有明确引用。

## 9. TargetVariant 与交付等级

```ts
export type DeliveryLevel =
  | "not_started"
  | "structural"
  | "previewable"
  | "install_candidate"
  | "install_verified"
  | "blocked";

export interface TargetVariantV1 {
  schemaVersion: 1;
  outlet: Outlet;
  capabilities: CapabilitySnapshot;
  previewProfile: PreviewProfileRef;
  assetSet: AssetSet;
  buildStatus: OutletBuildStatus;
  deliveryLevel: DeliveryLevel;
  qaReportIds: string[];
  artifact?: PackageArtifactV1;
  installEvidenceId?: string;
  diagnostics: Diagnostic[];
}
```

升级条件：

- `structural`：adapter contract 与包结构报告通过。
- `previewable`：真实浏览器基于 outlet profile 完成规定交互，且预览加载目标资产。
- `install_candidate`：版本 confirmed、必需资产完整、QA error 为 0、包级校验通过。
- `install_verified`：指定客户端/设备 evidence manifest 通过且 hash 对应同一 artifact。
- Evidence 过期或客户端主版本变化时可降级为 `install_candidate`，不能保留虚假绿色状态。

## 10. OutletJob

```ts
export type OutletJobStage =
  | "not_started"
  | "queued"
  | "generating_assets"
  | "adapting"
  | "qa"
  | "packaging"
  | "succeeded"
  | "failed"
  | "cancelled";

export interface OutletJobV1 {
  schemaVersion: 1;
  id: string;
  projectId: string;
  versionId: string;
  outlet: Outlet;
  stage: OutletJobStage;
  progress: number;
  attempt: number;
  queuedAt: string;
  startedAt?: string;
  finishedAt?: string;
  retryable?: boolean;
  diagnostic?: Diagnostic;
}
```

规则：

- `progress` 为 0..1，但 UI 主要展示 stage，不伪造平滑百分比。
- 四出口各有 job；一个失败不改变其他 job。
- 本地模式也需要并发上限、任务数量上限、TTL、取消和重试语义。
- Job ID 不得使用可枚举的全局自增 ID。

## 11. Feedback 与 ChangeInstruction

```ts
export interface FeedbackV1 {
  schemaVersion: 1;
  id: string;
  projectId: string;
  versionId: string;
  inputMode: "free_text" | "element_pick" | "region_select";
  text: string;
  selectedElementIds: string[];
  selectedRegion?: NormalizedRect;
  createdAt: string;
  instruction?: ChangeInstructionV1;
  resultingVersionId?: string;
}

export interface ChangeInstructionV1 {
  schemaVersion: 1;
  category: "asset_param" | "layout" | "style" | "platform" | "interaction";
  targetElementIds: string[];
  targetOutlets: Outlet[];
  operation: "set" | "adjust" | "replace" | "remove" | "regenerate";
  fieldPath: string;
  value?: unknown;
  delta?: number;
  preserveElementIds: string[];
  confidence: number;
  reason: string;
}
```

不变量：

- `confidence < 0.7` 默认需要用户确认目标；具体阈值可由 ADR 调整。
- `platform` 类指令必须至少有一个 targetOutlet。
- element_pick/region_select 必须保存选区上下文，不能只把中文目标词拼进 text。
- 执行后必须产生字段级 diff；未改变任何字段时不能伪装成成功版本。
- 用户显式满意标记是硬保护；推断满意只进入项目偏好，不进入 preserveElementIds 的硬保护集合。

export interface QAReportV1 {
  schemaVersion: 1;
  id: string;
  projectId: string;
  versionId: string;
  outlet?: Outlet;
  artifactId?: string;
  gate: "schema" | "assets" | "render" | "adapter" | "consistency" | "browser" | "install" | "performance" | "security";

  code: string;
  stage: string;
  severity: "info" | "warning" | "error";
  userMessage: string;

错误信息不能只是一段 Error.message；用户文案与技术细节分离，secret 和用户原始素材不得进入 technicalMessage。

## 14. Provenance

```ts
export interface Provenance {
  schemaVersion: 1;
  stage: "A1" | "A2" | "A3" | "A4" | "A5" | "A6" | "migration";
  inputHashes: Record<string, string>;
  outputHash: string;
  implementationVersion: string;
  dependencyVersions: Record<string, string>;
  provider?: { id: string; model: string; endpointHost: string };
  randomSeed?: string;
  fallback?: { used: boolean; reason?: string };
}
```

`provider` 不含 API Key，不保存完整 URL query。相同输入与相同 seed 的确定性阶段应产生相同 outputHash；平台要求的时间/GUID必须由可注入 factory 产生并记录。

## 15. Snapshot 和迁移

```ts
export interface DesignSnapshotV1 {
  schemaVersion: 1;
  brief: DesignBriefV1;
  visualSpec: VisualSpecV1;
  elements: ElementCatalog;
  assetBundle: AssetBundleV1;
  targetVariants: Record<Outlet, TargetVariantV1>;
  preferences: ProjectPreference[];
  provenance: Provenance[];
}
```

迁移策略：

1. 读取文件先检查容器版本和大小上限。
2. `parseUnknownSnapshot(input)` 做运行时校验，不使用直接类型断言。
3. 旧 `ProjectStoreSnapshot` 走 `migrateLegacyProjectStore()`。
4. 旧 `Version.data` 中的 brief/spec/skin/variant/qa 转成 DesignSnapshotV1；缺失 AssetBundle 时标记 incomplete，不伪造资源。
5. 旧 `ready` 只迁移为生命周期 ready；所有出口 deliveryLevel 最高为 structural。
6. 旧 `exported` 迁移为 completed，并产生 `LEGACY_EXPORT_NOT_INSTALL_VERIFIED` warning。
7. 未知字段默认放入 migration report；不能静默丢失用户可见数据。
8. 迁移结果重新计算 hash，原始文件不覆盖。

## 16. 不可变性和合并

- Store 写入时深冻结或结构化克隆；读取返回不可变快照。
- fork 继承父 snapshot，但任何变更生成新对象，不能共享可变嵌套引用。
- 元素合并使用 element catalog 找到 tokenPaths/assetRoles；不再比较 `data[elementId]`。
- 合并输出 MergeRecord：

```ts
interface MergeRecord {
  sourceVersionId: string;
  targetVersionId: string;
  elementId: string;
  changedPaths: string[];
  conflicts: { path: string; resolution: string }[];
}
```

- 没有对应 element 或没有差异时返回明确结果，不创建空版本节点。

## 17. 当前代码到目标契约的迁移顺序

1. `DOM-001` 建 `@imskin/contracts`，先定义 Outlet、DeliveryLevel、Diagnostic、Artifact 和 TargetVariant。
2. `skin-gen` 兼容导出 DesignBrief/VisualSpec/SkinManifest，增加转换器，不立即删除旧类型。
3. `DOM-002` 实现 DesignSnapshotV1 parser/migration 和深层不可变 ProjectStore。
4. `feedback-core` 输出 ChangeInstruction，旧文本 API 保留 adapter。
5. `orchestrator` 改为按 TargetVariant 重跑并生成 OutletJob/Artifact。
6. `api/web-app` 只消费公共契约，不自行发明状态字符串。
7. 完成所有旧项目 fixture 的 round-trip 后，才废弃 `Record<string, unknown>`。

## 18. 契约完成标准

- 公共契约有单一导出位置和运行时 parser。
- schema、迁移、状态机、element path、深层不可变和 artifact 均有测试。
- 旧 `.imskin.json` fixture 可导入；迁移 warning 可见。
- 四出口使用同一 Outlet enum 和 DeliveryLevel。
- API、Web、Orchestrator 不再各自定义近义状态。
- 没有证据的产物不能通过类型或转换器获得 `install_verified`。
