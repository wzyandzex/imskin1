# IMSkin 路线图与任务分解

> 版本：v1.0
> 状态：可执行任务清单
> 最后更新：2026-08-15
> 关联：`docs/00-总规划与开发基线.md`（Phase 划分）、`docs/03-质量门禁与验收协议.md`（Gate）

## 0. 使用方式

- 每个任务是一个可独立验收的垂直切片；禁止“接入四出口”式笼统任务。
- 开始任务前确认依赖已完成；完成后按 `docs/04` §8 的 DoD 检查并更新本文状态列与 Handoff。
- 状态：`todo / doing / review / done / blocked`。
- 任务粒度以“一个 PR 可完成、一个验收标准可判定”为准；过大就拆子任务（如 UX-001a）。

## 7. Phase 6：安全、可靠性与工程门禁（共享/对外前强制）

| ID | 任务 | 范围 | 验收标准 |
|---|---|---|---|
| SEC-001 | API 安全基线 | 非 loopback 强制 key；常量时间比较；job/artifact 随机 ID；body/下载/TTL/并发限制；错误码 | 安全测试（L9）覆盖并通过 |
| SEC-002 | 网络边界 | baseUrl/图片 URL：URL 解析、协议/私网/metadata 拒绝、重定向复验、大小/MIME/超时 | SSRF 测试矩阵通过 |
| SEC-003 | 密钥与隐私 | 前端默认不持久化 Key；直连风险明示；项目导出无 secrets；provider 数据流向可见 | 泄露扫描 + UI 提示测试 |
| ENG-001 | 工程门禁 | 根 tsconfig + references；lint；CI（L0–L4）；Chromium E2E 骨架（L5） | `npm run ci` 一键全绿 |
| OBS-001 | 观测 | 结构化日志与指标（stage/outlet/时长/fallback/QA/反馈轮次/漂移率；不含素材与 secret） | 关键路径事件可查询 |

## 8. Phase 7：延后能力（另立 PRD/ADR 后启动）

模板/IP 库、公开分享、云端多租户/对象存储、MCP、跨项目偏好、协作、批量生产。在黄金出口 + 门禁完成前不排期。
