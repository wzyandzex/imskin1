# ADR-001 渐进式出口发布与“可安装”定义

- 状态：已接受（2026-08-15）
- 关联：`docs/00` §1、`docs/02` §2、`docs/03` §3

## 背景

现有文档同时存在“四出口可导出”与“真机验证未完成”两种表述，用户和开发者无法判断产物是否可安装。`exported` 状态、非空 ZIP、逆向结构确证被混用为交付证据。

## 备选方案

1. 二值“支持/不支持”——信息量不足，掩盖中间态。
2. 按里程碑整体宣布——一个慢出口拖累全部，或迫使虚报。
3. 每出口独立五级交付状态（structural/previewable/install_candidate/install_verified/blocked）。

## 决策

采用方案 3。四出口独立推进、独立报告、独立失败；只有 `install_verified` 可对用户称“可安装包”；UI 用词随等级变化（实验包/预览/待验证/可安装）。

## 后果

- 正面：承诺与证据对齐；慢出口不阻塞快出口体验；失败可见。
- 负面：状态管理复杂度上升；需要 Evidence 体系支撑。

## 迁移

旧 `VersionStatus.exported` 迁移为 `completed` 并附 `LEGACY_EXPORT_NOT_INSTALL_VERIFIED` warning。

## 回退

若五级过细，可先在 UI 合并显示三档（实验/待验证/可安装），内部仍存五级；不允许删掉等级本身。
