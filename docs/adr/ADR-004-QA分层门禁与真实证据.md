# ADR-004 QA 分层门禁与真实证据

- 状态：已接受（2026-08-15）
- 关联：`docs/03` 全文

## 背景

当前 `checkSkin` 只含单份可读性；image 背景仅 warning 且放行；跨出口一致性未接入闸门；导出前无资产/包结构/确认检查。“QA 通过”不构成任何交付结论。

## 备选方案

1. 保持单报告 + 布尔 passed。
2. 分层 Gate（G0–G8）+ 机器可读报告 + 状态由报告聚合计算。

## 决策

方案 2。Gate 顺序：确认→schema→资产→渲染→适配→一致性→浏览器→真机→性能/安全。error 阻断、warning 需用户确认并留痕、required 检查未运行等同 failed。关键普通文字对比度初始硬门槛 4.5；图片/复杂渐变必须实际渲染后采样。

## 后果

- 正面：“可安装”有可审计依据；位图遮挡不再漏过。
- 负面：导出链路变慢；需要修复-重检循环（限一次自动修复）。

## 迁移

`checkSkin` 成为 G3 的静态子集；`checkConsistency` 并入 G5；一键修复必须产生版本树节点。

## 回退

阈值调整（如大字号 3:1）须有样本数据与新 ADR，不允许直接改常量绕过。
