# ADR-008 资源不完整时的诚实降级

- 状态：已接受（2026-08-15）
- 关联：`docs/03` §7.2、R-08

## 背景

图像生成依赖用户配置 endpoint，缺省时导出多为配置骨架（`imageCount=0`）；存在用空图/占位图掩盖缺失、或把骨架包当正式包的诱惑。

## 备选方案

1. 无图像服务时拒绝一切生成——扼杀离线可用性与确定性路径价值。
2. 填透明占位图保持“结构完整”——伪造完整性，QA 与用户都被欺骗。
3. 允许合法降级但显式标注：纯色/渐变为合法设计资源；位图必需时缺口进 missingRoles 并阻断 install_candidate；实验导出必须 `experimental=true`。

## 决策

方案 3。降级链：目标资源 → 确定性替代（重走 QA 并记 fallback provenance）→ 缺失（TargetVariant incomplete，不产假包）。UI/CLI 对 incomplete 与 experimental 的表述强制区分于正式包。

## 后果

- 正面：离线可用；完整性不可伪造；用户永远知道拿到的是什么。
- 负面：无图像服务时部分出口无法达到 install_candidate（如实呈现）。

## 迁移

`exportSkinSet` 默认空 images 的行为改为“产出实验包并声明缺失”，前端导出卡片展示缺失角色清单。

## 回退

无（占位图方案被原则性否决）；替代资源策略可按出口 AssetProfile 调整。
