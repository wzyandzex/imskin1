# ADR-009 G5 一致性度量：CIEDE2000 替代 RGB 欧氏距离

- 状态：已接受（2026-08-18）
- 关联：docs/03 §10 G5、R-10、ADR-004

## 背景

跨出口一致性检查（G5）原用 RGB 欧氏距离做色差度量，阈值 0.2（归一化 0..1）。问题：
1. RGB 空间非感知均匀——绿-蓝区差异被放大、红区被压缩；
2. 阈值 0.2 为经验值，无感知学依据；
3. 真实搜狗/百度双出口样本不可用（无客户端），无法用样本回归校准。

## 备选方案

1. **保持 RGB 距离**——简单但感知不准确（拒绝理由：绿区误报/红区漏报）。
2. **CIELAB ΔE\*ab（1976）**——比 RGB 好，但在蓝区仍有较大偏差。
3. **CIEDE2000（ΔE₀₀）**——CIE 推荐的感知均匀度量，业界标准（Sharma et al. 2005 完善实现注记）；有官方测试向量集验证正确性。

## 决策

采用方案 3：**CIEDE2000 (ΔE₀₀)**，阈值 **5.0**。

阈值依据：
- Sharma 2005 量标：ΔE 2-10 = "一眼可见"；<2 = "近观察可见"。
- 取 5.0（2-10 区间中低值）：允许平台定向反馈产生的受控色偏（PIPE-001 的候选颜色调整通常 ΔE < 3），但阻拦"像两套设计"的分叉（如红→蓝 ΔE > 30）。
- 位图/渐变：gradient 取中点代表色；image 降级 undecidable（待 Canvas 渲染后取样，Canvas 采样点 → RGB → CIEDE2000 走同一通路）。

## 实现与验证

- `qa-core/src/ciede2000.ts`：纯 TS 零依赖（sRGB→Lab D65 + CIEDE2000 公式完整 22 步）。
- Sharma 2005 Table 1 官方向量 8 对（覆盖 hue wrap / chroma 边界 / RT 项），容差 ±0.0001，**全部通过**。
- `consistency.ts` 替换 `normalizedDistance` → `ciede2000RGB`。
- 阈值 `CONSISTENCY_MAX_DELTA_E = 5.0` 导出为公共常量。
- `orchestrator.outletDeliveryLevel` G5-② 接入：覆盖出口 vs 主设计的 ΔE₀₀ > 5 → blocker。

## 后果

- 正面：感知准确（绿蓝区不再误报）；阈值有感知学依据；官方测试向量保证实现正确性；纯 TS 零依赖不破坏核心包契约。
- 负面：计算略重（~20 FLOPs per comparison，对 2 个颜色对比可忽略）。
- 真机样本校准：当 E4 级真机安装证据可用时，可对比真实双出口截图做进一步阈值微调（届时本 ADR 附修订版）。

## 回退

若 CIEDE2000 在真实使用中产生过多误报，可临时放宽至 ΔE ≤ 8（仍远优于 RGB），或按品牌色/点缀色分别设定阈值（需要新 ADR）。
