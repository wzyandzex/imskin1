## 0. 一页速览

**是什么**：用一段设计意图（关键词/主色/情绪）自动生成输入法皮肤，并在网页里**像平常打字一样**实时预览、多轮自然语言反馈迭代、导出安装包。

**现在能做什么（浏览器里的完整闭环，`npm run dev -w @imskin/web-app` → http://localhost:5173/）**：

```
填意图(关键词/主色/情绪/圆角) → 生成皮肤(含可读性自检)
   → PC/手机 真实虚拟键盘上打字预览(真拼音引擎、九宫格T9、按键音、上滑/长按次字符、位图九宫格)
   → 一句自然语言反馈(「候选词字太小」「想再稳重点」「百度这边对不齐」)
        → 自动分类/路由/只重跑受影响的层 → 从当前版本 fork 出新版本
   → 左侧版本树(分叉连线)回看 / 并排对比改前改后
   → 导出四出口：搜狗PC .ssf / 搜狗Android .ssf / 百度PC .bps / 百度Android .bds
        （字段均经真实皮肤/APK 逆向确证；真实位图/真机安装待接入，见 §3）
   → 全程 localStorage 持久化(刷新不丢) + 重置
```

**质量**：13 个包，**305 个测试全绿**（222 node + 83 web-app vitest），`tsc` 零错误，`vite build` 通过。经**两轮多 agent 对抗性审查 + 2026-08 一次逆向协议落地 + A1 意图理解前端闭环 + FR-SHARE 分享/导回 + FR-QA-3 深浅双模式 + FR-PREVIEW-7 多机型 DPI 预览 + FR-FEEDBACK-5 点选反馈 + FR-EXPORT-2 一键修复 + FR-LEARN-1 偏好学习 + LLM 接入层 + 自动化 API + 设置中心/快捷键/多模型接入与切换器**，共发现并修复 **6 个真 bug**（见 §7）+ 新增四出口适配层（§1）+ A1 确定性意图理解 + 项目文件分享/导回 + 深浅双模式变体 + 多机型 DPI 档位预览 + 预览内点选反馈 + 导出一键修复 + 同项目偏好学习 + LLM 接入层（llm-core）+ 自动化 API（REST/CLI/SDK）。

**关键约束**：本环境**无法**完成的部分（外部阻塞，未编造）——见 §3。

## 5. 开发指南

**结构**：npm workspaces monorepo，`packages/*`。

```
packages/
  pinyin-engine   skin-gen   project-model   feedback-core   qa-core
  zip             sogou-adapter   sogou-mobile-adapter   baidu-pc-adapter
  baidu-mobile-adapter   orchestrator   web-app
```

**约定**：

- 引擎/逻辑包用 **Node ≥ 22 原生 TS 执行 + 原生测试运行器**，核心逻辑**零第三方依赖**即可跑测试。相对 import 带 `.ts` 扩展名；跨包用 `@imskin/*` bare specifier。
- 前端（web-app）用 React 19 + Vite 6 + Vitest（jsdom）。

**命令**：

```bash
# 装依赖（本机全局 npm 缓存有 EPERM，须用项目本地缓存）
npm install --cache ./.npm-cache

# 跑全部 node 包测试
node --test packages/{pinyin-engine,skin-gen,project-model,feedback-core,qa-core,zip,sogou-adapter,sogou-mobile-adapter,baidu-pc-adapter,baidu-mobile-adapter,orchestrator}/test/*.test.ts

# 前端：开发服务器 / 测试 / 构建
npm run dev  -w @imskin/web-app         # → http://localhost:5173/
npx vitest run --root packages/web-app
cd packages/web-app && npx tsc --noEmit && npx vite build
```
