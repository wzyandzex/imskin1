## 结论（诚实边界）

1. **引擎算法没问题，数据是瓶颈**：53 键自检 98.1% 命中 + 微秒级延迟，说明分词/检索/排序/翻页实现正确；60 个日常词仅 8.3% 命中、78% 无候选，种子词库（约 230 词条）完全不足以支撑"日常输入基本顺畅"（FR-PREVIEW-2 AC2）。产品文案维持"简化预览词库"标注。
2. **命中的 5 词恰为种子库收录词**（朋友/我们/你们/时间/世界）——common-60 实际测的就是"词在不在库里"。
3. **排序校准发现**：`xian` 输入下「西安」排第 4（被 先/现/线 压制）。原因是 SeedDict 以键内书写序位赋权（单字列表 rank 高于双字词），并非真实词频。**词库替换时必须携带真实词频数据**，否则多音节词仍会被单字列表压制（登记为 R-09 附注，与 R-10 校准族相邻）。
4. T9 无候选率（43%）低于 26 键（78%）：数字前缀索引天然更宽松，但同样是"仅有库内词可见"。
